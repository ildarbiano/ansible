HikariCP — это пул соединений с базой данных для Java-приложений.

Что это такое простыми словами:
Представь, что каждый запрос к БД — это звонок в банк. Если каждый раз набирать номер заново (устанавливать соединение), это долго. HikariCP — это "горячая линия" с готовыми операторами, которые ждут звонка.

text
Без HikariCP:
Запрос → Установка соединения (200ms) → SQL → Закрытие соединения

С HikariCP:
Запрос → Взять готовое соединение (1ms) → SQL → Вернуть в пул
Как это работает:
text
┌─────────────────────────────────────────────────────────┐
│  Spring Boot приложение                                │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │  HikariCP (пул соединений)                     │   │
│  │                                                 │   │
│  │  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ... ┌────┐      │   │
│  │  │ #1 │ │ #2 │ │ #3 │ │ #4 │     │#10 │      │   │
│  │  └────┘ └────┘ └────┘ └────┘     └────┘      │   │
│  │   ↑      ↑      ↑      ↑           ↑         │   │
│  │   └──────┴──────┴──────┴───────────┘         │   │
│  │          Готовые соединения                   │   │
│  └─────────────────────────────────────────────────┘   │
│                          │                              │
│                          ▼                              │
│                  PostgreSQL                             │
└─────────────────────────────────────────────────────────┘
При старте приложения HikariCP создаёт 10 соединений (по умолчанию) и держит их открытыми.

Когда приходит запрос — берёт готовое соединение, выполняет SQL, возвращает обратно.

Метрики HikariCP, которые у тебя есть:
Метрика	Значение	Что означает
hikaricp_connections_active	0	Сейчас активно 0 соединений
hikaricp_connections_pending	0	Никто не ждёт соединение
hikaricp_connections_max	10	Максимум 10 соединений в пуле
hikaricp_connections_idle	10	10 соединений свободны
hikaricp_connections_min	10	Минимум 10 соединений
